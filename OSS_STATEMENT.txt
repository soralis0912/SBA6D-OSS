RG620TSBK241106 Open Source Software Statement
==============================================

Scope
-----
This package provides the source code, configuration, patches and
build-related materials for the open source software used in this
product, in fulfilment of the applicable GPL/LGPL license obligations.

It is a source disclosure package, not the complete vendor SDK.

Baseline
--------
  Product revision : RG620TSBK00AAR03A01G4G_OCPU_01.001.01.001
  OpenWrt          : 21.02.7 (r16847-f8282da11e)
  Linux kernel     : 5.4.238
  OpenWrt target   : gem6xxx / evb6990_cpe_mt7990_emmc
  OpenWrt profile  : DEVICE_evb6990_cpe_mt7990_emmc_debug

Material not included
---------------------
Proprietary components, signing material, prebuilt modem binaries and
similar non-disclosable items are not included in this package.
EXCLUSIONS_JUSTIFICATION.tsv records what was excluded and why.

In package-info/openwrt-packages-package-details.tsv the "Disclose"
column marks each package: "Yes" for open source components whose
source is provided here (282), "No" for proprietary components not
subject to source disclosure (90).
